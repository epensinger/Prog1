Python tuples

A tuple is an ordered collection. Once you create one, you can read its items, but you can’t replace, add, or remove items in that tuple.

Explore a tuple ↓
coordinates.py
# Keep related values together
point = (4, 7)
x, y = point

print(x)  # 4
print(y)  # 7

Three tuple patterns

Predict what each snippet does, then reveal the result.

One item needs a comma

The trailing comma turns a single value into a tuple.

print(type(("kiwi")))
print(type(("kiwi",)))
<class 'str'>
<class 'tuple'>

Unpack into variables

Each variable receives the item in the matching position.

name, score = ("Ada", 9)
print(name, score)
Ada 9

Build a new tuple

Use + to combine tuples into a new tuple.

colors = ("red", "blue")
print(colors + ("gold",))
('red', 'blue', 'gold')
