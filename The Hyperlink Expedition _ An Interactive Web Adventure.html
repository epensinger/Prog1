Before you begin: what to know about the web

A webpage is one document. A website is a collection of pages, usually sharing a domain name. A hyperlink connects a page to another page or resource. The World Wide Web is a network of linked resources accessed over the internet. Links can point to pages on the same website or a different website. A link from A to B does not automatically create a link from B back to A.

The websites, artifacts, and clues in these expeditions are fictional. The web addresses are simulated within this HTML file. No real internet connection is needed.
